Project Title            :  Online Voting System

Team members(with roles) :

Problem Description      : Voters authenticate themselves securely. Votes are cast digitally. The system ensures
vote confidentiality. Results are generated automatically. This speeds up the election
process.      

How to run the code?
      1. Save the File
      2. Compile the Program
      3. Run the Program
      4. Login as Admin in Main Menu
      5. Add Candidates
      6. Add Voters with id and unique password
      7. Start Election
      8. Cast vote as voter
      9. End Election
      10. View Results
      11. Exit
